# CL-55309 rx_dma 수정: FIFO 임계값 설정 오류

## 변경 내용
ISSUE-2009 문제(DMA underrun 발생 후 PHY 재시작 실패)를 수정한다. `RX_DMA_CTRL` 레지스터 접근 순서를 바로잡고 RX DMA 를 재설정 한다.

## 영향 범위
rx_dma 모듈, HW rev B1. 코딩 규칙 RULE-ISR-001 준수 확인.

## 테스트
TC-RX-DMA-009 통과, 회귀 TC 12건 통과.
