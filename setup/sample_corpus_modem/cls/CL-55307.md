# CL-55307 clk_mgr 수정: 클럭 도메인 교차 시 동기화 없이 레지스터 접근

## 변경 내용
ISSUE-2007 문제(클럭 전환 중 hang)를 수정한다. `CLK_DIV_SEL` 레지스터 접근 순서를 바로잡고 클럭 매니저 를 재초기화 한다.

## 영향 범위
clk_mgr 모듈, HW rev A2. 코딩 규칙 RULE-ISR-001 준수 확인.

## 테스트
TC-CLK-MGR-007 통과, 회귀 TC 12건 통과.
