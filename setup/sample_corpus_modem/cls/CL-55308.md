# CL-55308 phy_ctrl 수정: DMA descriptor 정렬 오류

## 변경 내용
ISSUE-2008 문제(RX 경로 FIFO overflow)를 수정한다. `PHY_RST_REG` 레지스터 접근 순서를 바로잡고 PHY 컨트롤러 를 동기화 한다.

## 영향 범위
phy_ctrl 모듈, HW rev B1. 코딩 규칙 RULE-REG-002 준수 확인.

## 테스트
TC-PHY-CTRL-008 통과, 회귀 TC 12건 통과.
