# 샘플 코퍼스

`setup/install.bat` 이 `corpus/` 가 비어 있을 때 이 폴더의 문서를 복사합니다. 합성 데이터이며 형식 예시용입니다.
자기 문서(.md .txt .html .pdf)를 `corpus/` 에 넣거나 `config.json` 의 `corpus_dirs` 를 실제 폴더로 바꾸세요.

문서 형식 팁 (규칙 기반 그래프 추출이 잘 잡는 패턴):
- `# 제목` / `## 섹션` 헤딩 — 청킹 단위
- `### D1. 결정 제목` + `- **담당**: X` `- **마감**: 날짜` `- **금액**: 1,500억원` — 결정/담당/마감/금액 관계
- `## 참석` 다음 줄에 참석자 나열 — attendee 관계
- `- **기관 (5/15)**: "코멘트"` — comments_on 관계
- `출처: ...` — source 관계
