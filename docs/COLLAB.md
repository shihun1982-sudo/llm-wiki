# COLLAB — 휘발성 채팅과 게시판 (Web UI 부수 기능)

> 대상: 이 위키를 함께 쓰는 팀. 화면을 보다가 바로 말을 걸고, 남길 만한 것만 게시판에 올리는 용도.
> **부수 기능이다.** 토글 하나로 끌 수 있고, 꺼도 질의·빌드·MCP 는 그대로 동작한다.
> 설계 배경: [IMPLEMENTATION_PLAN_0916.md](history/2026-09-16/IMPLEMENTATION_PLAN_0916.md) §7 · 구현 `llmwiki/collab.py`

## 0. 한 장 요약

| | 채팅 | 게시판 |
|---|---|---|
| 어디에 | Web UI 왼쪽 사이드바 **최상단 고정**(기본 접힘). 말은 **화면의 내 아이콘 위 말풍선**으로 뜬다 | Evolve › **게시판** 탭 |
| 남는가 | **아니다.** 서버 메모리에만, `retain_min`(기본 120분) 뒤 사라짐. 서버를 재시작하면 빈다 | **그렇다.** `data/collab/board.json` |
| 어떻게 올리나 | 그냥 입력 | 채팅창의 **게시** 버튼(또는 `/게시 제목`) → 가운데에 작성 창이 뜬다 |
| 작업 연결 | – | 게시할 때 **내 최근 작업(요청)** 을 골라 붙인다 → 나중에 "무슨 질의에 대한 피드백인가" 를 따라갈 수 있다 |
| 권한 | 읽기/쓰기 = `read`(로그인한 사람) | 내 글 삭제는 본인, 남의 글 삭제·채팅 비우기는 `admin` |

## 1. 쓰는 법

채팅창은 **두 줄**이다.

| | 내용 |
|---|---|
| 1줄 | **가장 최근 대화 한 줄**(계속 갱신) + **[챗]** + **[게시]** |
| 2줄 | `챗` 을 켰을 때만 보이는 **입력칸** (아이콘 고르기 · 메시지 · 보내기) |

**[챗]** 하나가 입력칸과 **화면의 접속자 아이콘을 함께** 켜고 끈다(내 브라우저에만 적용되고 브라우저에 기억된다).
끄면 사이드바에 한 줄만 남고 아이콘도 사라진다.

1. `챗` 을 켜고 입력칸에 친다.
   - 보낸 말은 채팅 목록에 쌓이지 않고 **내 아이콘 위에 말풍선**으로 뜬다 — 아이폰 메시지처럼
     내 것은 파란색(오른쪽 꼬리), 남의 것은 회색(왼쪽 꼬리).
   - 1줄째에는 **가장 최근 한 줄**만 계속 보인다.
   - 입력칸 왼쪽에 **내 아이콘**이 보인다. **고를 수 없다** — 접속 IP 의 SHA-1 으로 정해진다(도구·계측기·부품 32종).
     랜덤이 아니라서 같은 자리(같은 PC)에서 오면 늘 같은 아이콘이고, 새로고침이나 서버 재시작에도 바뀌지 않는다.
     그래서 "저 아이콘은 누구 자리" 가 눈에 익는다. 자리를 옮기면(IP 가 바뀌면) 그 자리의 아이콘으로 바뀐다.
     **남의 IP 는 화면으로 나가지 않는다** (아이콘만 보인다).
2. 남겨야 하면 채팅창의 **게시** 버튼을 누른다 (채팅에 `/게시 제목` 을 쳐도 같다).
   - 화면 가운데에 작성 창이 뜬다. **내용** 에는 클립보드의 표·로그·텍스트를 그대로 붙여 넣어도 된다.
   - **연결할 작업** 드롭다운에 내 최근 요청 20건이 나온다. 피드백이 어떤 질의에 대한 것인지 고르면 함께 저장된다.
   - 종류: 피드백 / 질문 / 기록 / 문제. `Esc` 또는 바깥을 누르면 닫힌다.
3. 올린 글은 Evolve › **게시판** 에서 보고, 댓글을 달고, **해결로 표시**할 수 있다.

### 1.1 여러 사람이 접속하면 — 아이콘은 실시간으로 움직인다

접속자마다 **캐릭터(이모지)** 가 하나씩 화면에 뜬다. 자리와 마지막 말은 서버가 들고 있고
화면은 **1초마다** 받아 오므로, **다른 사람이 자기 아이콘을 옮기면 내 화면에서도 따라 움직인다**
(위치가 튀지 않게 0.35초 전환을 준다). 내 아이콘만 끌 수 있고, 끄는 동안에는 서버 값으로 되돌리지 않는다.

- 위치는 화면 **비율(0~1)** 로 저장되어 해상도가 달라도 같은 자리에 온다.
- 오래 머물수록 말풍선 글씨가 커진다 — 기본 **30분에 1px**, 상한까지. 값은 §2 에서 관리자가 정한다.
- `idle_hide_min`(기본 240분) 동안 아무 것도 안 하면 캐릭터가 사라진다.

### 1.2 1초 폴링이 서버에 부담이 되지 않는 이유 (최적화)

| 무엇 | 어떻게 |
|---|---|
| **읽기 슬롯을 잡지 않는다** | `reqmgr.weight_for_level` 이 `collab…` 작업에 `none` 을 준다. 예전에 `read` 로 두었더니 폴링만으로 슬롯이 차서 질의가 밀렸다 — [VERIFICATION_0916_2.md](history/2026-09-16/VERIFICATION_0916_2.md) §2.7.1 |
| **바뀐 게 없으면 목록을 안 보낸다** | 화면이 `rev`(접속자 목록 개정 번호)를 같이 보내고, 서버는 같으면 `people_unchanged: true` 만 돌려준다 |
| **새 메시지만 보낸다** | `since`(마지막 메시지 id) 이후만 |
| **말풍선 문구를 미리 저장한다** | 조회 때마다 메시지를 거꾸로 훑지 않는다 (30명×500건 = 매 폴링 15,000회 비교 → O(1)) |
| **DB 를 쓰지 않는다** | 채팅·접속자는 서버 메모리에만. 게시글만 파일 한 개 |

실측 (30명이 1초마다 폴링):

| | 최적화 전 | 지금 |
|---|---|---|
| 응답 크기 (변화 없을 때) | 7.9 KB | **0.5 KB** (93% 절감) |
| 대역폭 | 238 KB/s | **16 KB/s** |
| 서버 CPU | 0.5% | **0.46%** |

10명이 동시에 움직이는 동안 RAG 질의 0.98초, MCP `tools/list` 0.03초, `wiki_query` 0.06초로 영향이 없었다
(`python tools/verify/verify_collab_many.py`).

## 2. 설정 — `server.json` 의 `collab` 절

값은 모두 파일에 있다. 바꾼 뒤에는 Observability › 서버 모니터의 "설정 다시 읽기"(또는 서버 재시작).

| 키 | 기본 | 뜻 |
|---|---|---|
| `enabled` | `true` | 끄면 API 가 404 이고 화면에서 채팅창·게시판 탭이 사라진다 |
| `retain_min` | 120 | 채팅을 메모리에 두는 시간(분). 지나면 사라진다 |
| `max_messages` | 500 | 메모리에 두는 최대 메시지 수 |
| `max_chars` | 2000 | 메시지 한 건의 최대 길이 |
| `board_max` | 2000 | 게시판 글 최대 수 |
| `board_keep_days` | 365 | 게시글 보존 기간(일). 0 = 지우지 않음 |
| `bubble_font_start_px` | 12 | 말풍선 **시작** 글자 크기 |
| `bubble_font_step_px` | 1 | 한 번에 키우는 크기 |
| `bubble_font_step_min` | 30 | **몇 분마다** 키울지 |
| `bubble_font_max_px` | 28 | 상한 (계속 커지지 않게) |
| `idle_hide_min` | 240 | 이만큼 조용하면 캐릭터를 숨긴다(분). 0 = 계속 표시 |

전체를 끄는 스위치는 두 군데다 — 둘 중 하나만 꺼도 꺼진다.
- `config.json` 토글 **`collab`** (사이드바 Evolve·System 그룹에도 있다)
- `server.json` 의 `collab.enabled`

## 3. 본체에 영향을 주지 않는다는 뜻

이 기능은 "있으면 좋은 것" 이므로, 고장 나도 위키가 멈추면 안 된다. 그래서:

- **저장이 분리되어 있다.** 채팅은 메모리, 게시판은 `data/collab/board.json`. 색인 DB 를 건드리지 않는다.
- **API 가 독립적이다.** `/api/collab` 하나뿐이고, 꺼져 있으면 404 를 준다.
- **화면이 조용히 포기한다.** 폴링이 연속 5회 실패하면 스스로 멈추고, 그 뒤로는 다른 화면에 관여하지 않는다.
- **캐릭터 레이어는 클릭을 가로채지 않는다** (`pointer-events` 가 캐릭터 자신에만 있다).
- **질의 경로에 코드가 없다.** `llmwiki/collab.py` 는 질의·빌드·MCP 어디에서도 import 되지 않는다.

## 4. 권한

| 하는 일 | 등급 | 작업 이름(권한 표에서 바꿀 수 있음) |
|---|---|---|
| 채팅 읽기·쓰기, 게시, 댓글, 해결 표시, 캐릭터 이동 | `read` | `collab say` · `collab post` · `collab reply` · `collab resolve` · `collab touch` |
| 남의 글 삭제, 채팅 전체 비우기 | `admin` | `collab admin` |

내 글은 admin 이 아니어도 지울 수 있다. 조직 기준이 다르면
`security.json` 의 `permissions.ops` 에서 위 작업 이름으로 바꾼다 ([SECURITY.md](SECURITY.md) §4).

## 5. 확인

```bat
curl -s http://127.0.0.1:8765/api/collab
curl -s -X POST http://127.0.0.1:8765/api/collab -H "Content-Type: application/json" -H "X-Requested-With: llmwiki" -d "{\"action\":\"say\",\"text\":\"안녕\"}"
python tools\verify\verify_web.py                          :: collab 13항목 포함
python tools\verify\verify_collab_many.py --people 10      :: **여러 명 접속 시뮬레이션** (아래)
```

`verify_collab_many.py` 는 격리 서버에 계정 N개를 만들고 **N명이 동시에 아이콘을 움직이며 말하게** 한 뒤,
헤드리스 브라우저로 화면을 열어 실제로 확인한다 — 내 화면에 아이콘이 N개 보이는가, 남이 움직이면 따라 움직이는가,
말풍선이 뜨는가, `챗` 을 끄면 함께 사라지는가, 그리고 **그동안 RAG 질의와 MCP 가 멀쩡한가**.
화면 스크린샷(`tools/verify/collab_many_<N>.png`)도 남기므로 눈으로도 볼 수 있다.

증상별:

| 증상 | 원인 |
|---|---|
| 채팅창이 안 보인다 | 토글 `collab` 이 꺼짐 또는 `server.json collab.enabled=false` (API 가 404 면 화면이 숨긴다) |
| 아이콘이 안 보인다 | **[챗]** 이 꺼져 있다 (입력칸과 함께 켜고 꺼진다). 또는 `idle_hide_min` 동안 조용했다 |
| 보낸 말이 채팅창에 안 보인다 | **정상이다.** 말은 창에 쌓이지 않고 내 아이콘 위 말풍선으로 뜬다. 1줄째에 최근 한 줄만 |
| 다른 사람 아이콘이 안 움직인다 | 그 사람이 옮기지 않았거나, 폴링이 멈췄다(연속 5회 실패 시 자동 중단 — 새로고침) |
| 아이콘을 바꾸고 싶다 | **고를 수 없다.** 접속 IP 로 정해진다 (같은 자리 = 같은 아이콘). 목록 자체는 `llmwiki/collab.py` 의 `EMOJI` |
| 여러 사람이 같은 아이콘이다 | 아이콘이 32종이라 IP 가 달라도 가끔 겹친다. 이름은 말풍선·툴팁에 나온다. 더 늘리려면 `EMOJI` 에 추가 |
| 같은 PC 에서 둘이 쓰는데 아이콘이 같다 | IP 가 같으면 같은 아이콘이다 (의도한 동작). 사람 구분은 이름으로 |
| 내 글이 사라졌다 | **채팅은 휘발성이다.** `retain_min` 이 지났거나 서버가 재시작됐다. 남겨야 하면 **게시** 버튼 |
| 게시판 글이 오래된 것부터 없다 | `board_keep_days` / `board_max` |
| 캐릭터가 안 보인다 | `idle_hide_min` 동안 아무 것도 안 했다. 아무 말이나 입력하면 다시 나타난다 |
| 말풍선이 너무 커졌다 | `bubble_font_max_px` 를 낮추거나 `bubble_font_step_min` 을 늘린다 |

|---|---|
